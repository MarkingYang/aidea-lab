# Dyna 学习材料：研究基础与路线对比核查

核查日期：2026-10-28。范围限于作者论文、作者项目页及厂商原始披露。本文不是采访逐字稿；没有核实的视频经历、动机和直接引语不能据此补写。未运行任何机器人、模型或实验。

## Jason Ma 的研究主线：共享问题，不是线性替代

作者主页把自己的研究概括为利用基础模型与互联网数据帮助机器人学习，包括视觉奖励、LLM 辅助学习及 VLM 价值函数。可以据此将主线概括为“如何把可扩展的人类知识转成机器人可用的学习信号”，但这属于编辑归纳。不能写成 VIP 失败所以 Eureka 取代它、Eureka 失败所以 GVL 取代它。它们分别改变表征/奖励、奖励程序搜索和进度估计，方法可以互补。[作者主页](https://jasonma2016.github.io/)

### VIP：Value-Implicit Pre-training

论文 2022-09-30 首次提交，发表于 ICLR 2023。将人类视频表征学习构造成离线、目标条件价值学习，推导不依赖动作标签的自监督目标；通过表征空间中当前图像与目标图像的距离形成平滑视觉奖励。预训练使用 Ego4D；冻结表征可用于下游机器人控制。它输出的主要是表征与奖励依据，不是把人类视频直接变成机器人关节动作。论文报告部分真机离线 RL 设置只需 20 条轨迹，不能泛化为“任意任务 20 条就能学会”。[VIP 论文](https://arxiv.org/abs/2210.00030)

**推导出的边界：** 图像目标可能掩盖接触、力度或物体内部状态；视觉接近目标不等于任务已经满足全部约束。

### Eureka：LLM 生成并迭代 reward code

论文 2023-10-19 首次提交，发表于 ICLR 2024。LLM 生成奖励函数代码，通过 RL 训练与反馈筛选、改进奖励。LLM 不直接执行低层控制，RL 学出的策略才负责动作。论文在 29 个开源 RL 环境、10 种机器人形态上评估，83% 任务优于相应人工奖励，平均归一化改进 52%；这些是特定 benchmark 结果，不能写成工业生产成功率。转笔示例是模拟 Shadow Hand。[Eureka 论文](https://arxiv.org/abs/2310.12931)、[项目与代码入口](https://eureka-research.github.io/)

**推导出的边界：** 自动生成奖励仍依赖环境接口、可观测变量及评价函数；reward hacking、仿真偏差和错误目标并不会自动消失。

### GVL：Generative Value Learning，不是“生成奖励代码”

论文名为 *Vision Language Models are In-Context Value Learners*，2024-11-07 首次提交，发表于 ICLR 2025。GVL 把视频帧打乱，让 VLM 根据任务语义判断完成进度；目的是减少按时间顺序“猜测进度”的捷径。它无需机器人或任务特定的模型训练，即可在上下文中进行 zero-shot/few-shot 进度估计；论文展示数据筛选、成功检测及策略学习用途。[GVL 论文](https://arxiv.org/abs/2411.04549)、[作者项目](https://generative-value-learning.github.io/)

**边界与解释：** task progress / temporal value 不是接触力估计，也不等于经过校准的生产合格概率。项目的 Value-Order Correlation 衡量预测值与专家视频时间顺序的秩相关，依赖高质量专家示范通常随时间取得进展的假设。可循环、回退或视觉难区分的任务需要单独检查。这些限制是基于方法的分析，不应冒充原视频结论。

## 供正文压缩使用的路线矩阵

| 对象与范围 | 公开路线 | 数据与身体 | 可以支持的比较 | 不能据此推出 |
| --- | --- | --- | --- | --- |
| Dyna-2（2026-08） | WAM，将未来视觉与动作建模结合 | 百万小时第一视角人类数据预训练；报告机器人后训练实验 | 重点检验人类数据规模及 world modeling 对迁移的作用 | 已解决所有身体、任务的 zero-shot 实机控制 |
| PI π₀（2024）及 π*₀.₆（2025） | VLM 基础加连续动作生成；后续结合自主经验、纠正与 RL | 多机器人、多任务数据及任务后训练 | 以机器人基础策略和适配能力为核心；不能只概括为行为克隆 | PI 不用人类知识、不做 RL，或与 WAM 永远互斥 |
| Skild Brain（2025 官方技术说明） | 高层低频策略与低层高频策略构成层级模型；强调 omni-bodied | 大规模仿真、互联网视频预训练，目标真机数据后训练 | 显式追求多形态适应，比较重点是身体覆盖与适配 | “any robot”愿景已成为所有本体的实证保证 |
| Figure：Helix（2025）到 Helix 2.5（2026-09） | 初版慢速 VLM 与快速动作策略；2.5 强调全身与陌生住宅泛化 | 自有人形硬件；2.5 用 Index 人类行为数据预训练再作任务适配 | 硬件、数据与模型协同，人类数据并非 Dyna 独有 | Figure 只用遥操作数据；住宅 zero-shot 等于没有任务适配 |

各行是不同任务、时期和评价口径下的技术重心，不能做数值性能排名。世界模型、VLA、层级控制、RL 与 imitation 是不同划分轴，不宜把公司永久分入互斥阵营。

### PI 的直接来源与限定

π₀ 从预训练 VLM 出发，结合公开及自采的多机器人数据，用 flow matching 产生连续动作，并可作任务后训练。[π₀ 官方介绍](https://www.pi.website/blog/pi0)

π*₀.₆ 使用 RECAP（RL with Experience & Corrections via Advantage-conditioned Policies），联合示范、人工纠正与自主执行经验。它说明“VLA 只能模仿成功示范”不是对模型类别的准确定义。[π*₀.₆ 官方介绍](https://www.pi.website/blog/pistar06)

### Skild 的直接来源与限定

Skild 的官方说明给出高层操作/导航策略和低层关节/力矩策略分工，以及仿真、互联网视频、目标真机数据的组合。其对竞争对手“缺乏真正物理理解”的评价属于公司观点，不应转述为研究定论。[Skild 技术说明](https://skild.ai/blogs/building-the-general-purpose-robotic-brain)

### Figure 的直接来源与限定

Helix 初版公开了慢速场景语义模块和快速动作模块，但这是 2025 年的具体架构，不能不加日期地代表后续所有版本。[Helix 原始介绍](https://www.figure.ai/news/helix)

Helix 2.5 已公开用 Index 人类行为数据预训练，从同一基础模型适配整理客厅、叠毛巾、铺床三种行为，并在 30 个未见家庭测试。这里的 zero-shot 指测试住宅与物体未用于现场适配，不是所有行为无任务训练。公司报告对照成功率从 9% 到 56%，不能与 Dyna 的离线预测准确率直接对比。[Helix 2.5 介绍与评测](https://www.figure.ai/news/helix-2-5-zero-shot-30-home-generalization)

### Dyna 的直接来源与限定

Dyna-2 的公开技术报告区分人类域离线评估、机器人离线迁移和后训练实机表现。对比表应保留这些层级，而不把预训练没有机器人数据缩写成整个训练和部署完全不需要机器人数据。[Dyna-2 技术报告](https://www.dyna.co/dyna-2)

## 三个可直接回答的问题

1. **Dyna 与 PI：** 就这里所比较的公开版本，Dyna 突出以世界预测目标吸收大规模人类操作视频；π₀ 突出 VLM、多机器人数据与连续动作策略，π*₀.₆ 又引入自主经验。是预训练与学习信号重点不同，不能归结为“一个懂物理，一个不懂”。
2. **Dyna 与 Figure：** 都在结合人类数据、模型与身体。差异更适合放在目标流程、身体形态和评估范围上，不能把“是否使用人类视频”当成永久分界。
3. **Dyna 与 Skild：** 都寻求可扩展数据和跨身体能力。Skild 在上述公开材料中更强调广泛形态的控制适应及仿真；Dyna-2 更明确呈现人类数据规模与 world-action 目标的实验链。单凭披露不能判断哪家总体更强。
