# 触觉篇深化：定向来源核查

2026-10-28。对照现有 `src/content/writing/robot-tactile-learning.md` 与[硅谷101署名稿](https://eu.36kr.com/zh/p/3973141981337223)。本记录只补具体机制与可用证据，不修改正文，不增加无关模型史。以下“可补解释”为作者教学推导，不能当作论文测量。

## 1. T-Rex 三专家：谁先算，谁接着改

**原始来源：**[论文第4节与附录B](https://arxiv.org/html/2606.17055v1)、[作者架构页](https://tactile-reactive-dexterous.github.io/)。

**可补事实：**latent expert负责未来视觉表示；action expert生成中间动作；tactile expert用新触觉继续细化。采样前6步由较慢动作通路完成，后4步由触觉通路完成，重用缓存，不重跑视觉塔。

**适合填入2.6：**先保留“杯子要移向托盘”的整体计划，再让接触反馈修改尚未执行的动作；这比抽象“快慢结合”具体。缓存的意义是把昂贵的场景理解成本分摊到多次接触修正。不要把latent expert直接写成自然语言规划器，论文的监督目标是未来视觉表示。

## 2. T-Rex 时间信息：最近发生过什么与此刻是多少

**原始来源：**[论文4.1、附录C](https://arxiv.org/html/2606.17055v1)、[官方代码说明](https://github.com/ZhuoyangLiu2005/T-Rex)。

**可补事实：**触觉输入结合16帧力/力矩历史的离散编码、当前连续力向量、当前形变图。项目以约5 Hz动作与20 Hz触觉更新说明两种节奏；这是分支更新设置，不是实测全链路延迟。

**可补解释：**两次当前力读数相同，最近持续上升或刚从峰值回落，可能意味着不同接触过程。历史编码提供趋势，当前值保留即时信息，形变图补空间分布。VQ-VAE不是自动消除全部漂移的保证。动作专家/触觉专家的频率也不等于底层伺服频率。

## 3. T-Rex 数据阶段：语义与动作先验如何接上真实接触

**原始来源：**[论文4.3及附录G](https://arxiv.org/html/2606.17055v1)、[官方仓库](https://github.com/ZhuoyangLiu2005/T-Rex)。

**可补事实：**预训练继承人类视频和重定向动作先验；中训练使用100小时同步机器人触觉；再做任务后训练。中训练围绕物体与操作原语组合，不只是重复完整任务。当前仓库开放约50小时子集，不能写100小时全部可下载。

**可补解释：**“先学拿、转、按的共同结构，再学这只手接触时的实际信号，最后学任务验收”，能解释为什么100小时并非从零学出全部能力，也不应直接与行业十万小时预测相减。

## 4. Tabero：语义通过目标力与控制接口落地

**原始来源：**[Tabero论文3.4–3.5](https://arxiv.org/html/2605.27886v1)、[官方项目](https://nathanwu7.github.io/Tabero/)。

**可补事实：**模型预测位置与目标力，固定混合控制器跟踪。夹持与对物体的施力分开处理；力反馈用于修正位姿或夹爪开度，夹爪通路还使用前馈、平滑和死区。论文通过提高力维度损失权重训练相关输出。

**可补解释：**语义决定希望怎样接触，传感器告诉系统实际接触怎样，控制器缩小两者偏差。“轻拿纸杯”不能仅靠更小的位置动作，因为相同开度对不同厚度与刚度会产生不同力。避免给不经坐标系确认的通用控制代码或把这个架构说成只有大模型闭环。

## 5. Tabero 语义力泛化与 T-Rex 的关系

**原始来源：**[Tabero第4.5节](https://arxiv.org/html/2605.27886v1)。

**可补事实：**模型对训练用轻/重语义及未见副词的力响应做比较；未见副词出现有意义的中间力，但成功率下降。主要定量来自其仿真基准，论文不宣称任意物体的真机语言力控已解决。

**可补解释：**Tabero重点回答“希望施加多大力怎样进入动作接口”；T-Rex重点回答“接触改变时如何在动作块内及时修正”。它们不是互斥流派：目标约束与快速修正可以在系统中互补，但论文没有直接验证两者组合。

## 6. Sparsh：独立编码还是联合学习，比较的是什么

**原始来源：**[官方训练说明](https://github.com/facebookresearch/sparsh)、[论文第4–6节与附录D.9](https://sparsh-ssl.github.io/sparsh.pdf)。

**可补事实：**Sparsh先自监督预训练，再冻结编码器、训练任务解码器。主要E2E对照使用同容量但随机初始化的编码器与解码器。Bead-maze实验把固定Sparsh接入Diffusion Policy，用触觉短历史和本体状态预测关节变化，衡量失败前通过距离。

**可补解释：**模块化路径在标签少、想复用表示时有吸引力；联合训练让表示为动作目标调整，但需足够数据及合适优化。这是设计判断。Sparsh结果并未把“强预训练后联合微调”与“冻结”在所有任务上判出永久赢家。表征评测、策略训练与真实闭环应分清。

## 7. 光学触觉算法：把“RGB算形变”补成一条可理解的链

**原始来源：**[MIT GelSight FAQ](https://people.csail.mit.edu/kimo/gelsight/faq.html)、[GelSight研究](https://www.mdpi.com/1424-8220/17/12/2762)、[GelSight Wedge原论文](https://gelsight.csail.mit.edu/wedge/ICRA2021_Wedge.pdf)。

**可补事实：**已知照明与反射涂层，利用标定物建立颜色到表面梯度的映射，再由梯度重建高度。Wedge的具体设计还在映射中加入像素位置以补偿照明沿表面变化；曲面胶体有助于改善覆盖和照明。

**可补解释：**这让结构、表面涂层和算法相互依赖：同样朝向在不同位置亮度可能不同，标定需考虑空间差异；重建高度之后仍需材料/加载标定才能估计力。可以保留视频的三类算法入口，但“光度立体必须RGB”“marker最多几十个”仅是采访中的简化，不能当作领域定理。

## 8. 材料、结构与量产：补回真实工艺，而不只列限制

**原始来源：**[DIGIT论文III-A–D](https://arxiv.org/html/2005.14679)、[一目官方](https://www.yimu.ai/zh-cn)、[硅谷101实验室走访](https://eu.36kr.com/zh/p/3973141981337223)。

**可补事实：**DIGIT公开的流程为制备均匀成像表层、基体固化，再用透明胶将胶体固定到窗口；模块化结构允许更换。论文明确厚成像层损失细节、薄层更易受损，并用规定载荷与磨耗行程测试。它是具体系统的例证，不代表所有工艺。

**视频细节可恢复但应标【视频】：**一目描述可恢复材料、压缩光学工作距离、曲面照明设计、BSDF测量后输入光学仿真，以及生产中的材料、光路、装配与标定一致性。当前官方公开页不足以独立验证自修复寿命、超表面方案细节或良率；可用走访叙述呈现研发问题，不必删除整段，也不把嘉宾产品数字当独立检验。

**可补解释：**一致性为什么重要：若胶厚/光源角度/粘接位置变化，同一接触产生的图像也会变化。工艺控制减少输入漂移，出厂标定吸收剩余差异，任务测试确认最终影响——这三步形成可教的制造闭环。
