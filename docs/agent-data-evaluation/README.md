## 可复验的本地实验

需要 Python 3 标准库，无额外依赖。仓库内执行：

```sh
python3 -m unittest discover -s docs/agent-data-evaluation -p 'test_*.py' -v
python3 docs/agent-data-evaluation/lab.py
```

独立下载包解压后执行：

```sh
python3 -m unittest discover -s . -p 'test_*.py' -v
python3 lab.py
```

`lab.py` 创建临时来源文件、评分器参考文件、固定候选成品和 SQLite 事件表，实际读写后执行检查，再清理临时数据。`results.json` 是实际执行的输出。四个候选成品属于两个来源家族，各重复两次：两个通过、一个错误金额失败、一个缺审计未知。已验收比例 2/4；固定的成本单位总计 5，每个通过成品 2.5。重复投递不增加事件数，重复试次不增加分母或成本。

`test_lab.py` 的 16 项检查覆盖有效成品、参考答案可见范围、金额、跨试次／跨来源成品、采集后修改、审计缺失、已知外发优先于缺证据、来源改写／删除、SQLite 事件去重与身份冲突、家族跨集合泄漏、计划试次缺失、试次去重／冲突、意外试次和完整汇总。

## 不应从实验推出什么

- 未执行 Codex、A/B/C 架构引擎、模型 API、真实 Agent、模型评委、训练或业务外发。
- 数值来自固定候选和人为成本，不是成功率估计、真实费用、框架排名或模型效果。
- `prepare` 生成参考答案，`collect` 构造可信采集器样例；真实场景需要独立终态读取和完整工具审计。攻击者若能改写整个可信采集／评分流程，本文检查无法提供保护。
- 文件夹和数据清单的分离不构成 OS 沙箱或认证隔离；没有执行真实用户、租户与访问控制验证。
- SQLite 检查是顺序单连接事务，不验证多写入者竞态、消息中间件、Outbox、分布式恰好一次或跨存储原子性。
- 家族校验验证显式 family 标记下的泄漏拒绝，不自动识别未标记近重复，也不实现时间切分。
- 删除传播、版本对象存储、训练数据撤回、生产凭据及发布流程仅为设计，没有在本实验实现。
- 评委混淆矩阵的 20/80、4/8 是文章中的独立算术示例，没有人工作业或模型评委校准结果。
