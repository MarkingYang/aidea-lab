## 证据

`early-research.md`、`foundation-research.md`、`recent-research.md` 记录作者论文、项目页面、机构历史档案、厂商与客户公告的日期和事实边界。文章引用 49 个不同的外部来源页面。

`sources.json` 是正文来源的补充 HTTP 响应记录，包含 URL、核验时间、响应状态、字节数与哈希；`record-sources.py` 可重新生成。没有保存来源全文。成功响应只标识收到的字节，不认证论文或厂商主张；部分来源受限流、拒绝访问或超时影响，原先的浏览器阅读核验与补充请求状态分别保留。`recent-source-responses.json` 是近期研究阶段的额外记录，可能与最终引用重叠。

需特别保留的口径：

- 1961 年是本文的工业应用起点，机器人学习也不是从 2015 年才开始。
- Shakey 包含执行反馈和恢复；Stanley 使用多个模块；Dactyl 的魔方解法来自现成算法。
- RMA 部署时通过推断更新环境表示，不在现场持续重训权重。
- SayCan 的技能选择、PaLM-E 的文本规划、RT-2 的动作输出是不同接口。
- Open X-Embodiment 的 2023-10-03 项目发布与 10-13 论文首稿分开；Octo 的 2024-05 指论文时间。
- ALOHA 是硬件与遥操作系统，ACT 是学习方法。遥操作采集并不等于评测时遥操作。
- AgiBot 使用固定 v1 来源；π₀ 采用“多机器人”表述，避开来源中不同配置数口径。
- Digit 引用客户于 2024-06-27 发布的具体物流部署公告，不把它当成全部机器人商业化的起点。
- Helix 2.5 的 30 个家庭、三类任务和 56% 整任务成功率是厂商披露；任务已在别处微调，zero-shot 指测试环境与物体。安全人工介入计失败。
